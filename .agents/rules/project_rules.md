# Project Rules for RSS Intelligence

## 1. Documentation Language Standard (双语文档规范)
- All Markdown documentation (`*.md`) created or modified in this repository MUST be bilingual (Chinese and English).
- 本项目创建或修改的所有 Markdown 文档 (`*.md`) 必须使用中英文双语呈现。

## 2. Git Commit Convention (Git 提交规范)
- All Git commit messages MUST be written in English using standard Conventional Commits format.
- 所有 Git commit 提交信息必须统一使用英文，并遵循 Conventional Commits 规范 (例如 `feat:`, `fix:`, `refactor:`, `test:`, `docs:`).
