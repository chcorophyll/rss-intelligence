# Project AGENTS Guidelines

## 1. Documentation Language (双语文档规范)
- All Markdown documentation (`*.md`) in this project MUST be bilingual (English & Chinese).
- 本项目中所有 Markdown 文档必须采用中英文双语编写。

## 2. Git Commit Convention (Git 提交规范)
- All git commit messages MUST be in English following Conventional Commits format.
- Git 提交信息必须统一使用英文。
